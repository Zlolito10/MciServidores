# Privacidad de asignaciones y fotografías

El listado de un evento combina una proyección `events/{eventId}/assignment_roster/{assignmentId}` con los documentos completos que el usuario está autorizado a leer. El roster conserva solo identificadores, rol real, estado de asignación y timestamps; no contiene asistencia, fotografías, ubicación ni notas. Los nombres se resuelven únicamente a partir del directorio público ya disponible. Si no hay nombre disponible, la interfaz lo indica sin inventarlo. La asistencia no se marca como pendiente/presente a partir del roster.

Las lecturas completas se restringen al propietario, administradores globales o responsable del área. Un rol `ministry_admin_A` o `ministry_subadmin_A` se limita a `A`, incluso si su array de ministerios es contradictorio. Los roles genéricos usan `assignedMinistries` como IDs; los nombres visuales de `areas` no conceden acceso. Attendance combina consultas autorizadas por propietario y por bloques de áreas. Un índice o permiso fallido produce un error, nunca una lectura global de respaldo. Los cambios de cuenta/alcance limpian los datos privados visibles y distinguen las claves de la caché en memoria.

Las fotografías nuevas de asistencia guardan el path de Storage. La vista normaliza también URLs antiguas para pedir el contenido al proxy del mismo origen con el ID token actual en el header o sesión cookie válida. No solicita URL firmada, no pone tokens en la URL/DOM, no envía Authorization a dominios externos y no guarda imágenes en CacheStorage. El contenido se muestra como blob temporal, con cancelación y revocación al desmontar. Se retira la caché antigua conocida `mci-images-cache-v1`, que podía contener fotos de asistencia; esto no revoca tokens de descarga históricos en Storage.

Las adaptaciones son reconstrucción nueva, reproducible con `scripts/reconstruct-frontend.mjs`; no son JSX original recuperado. Los fixtures y pruebas usan datos sintéticos. El backfill de rosters y cualquier migración/revocación de URLs en producción requieren su operación autorizada independiente; este cambio no ejecuta esas operaciones ni despliega.
